# Algoritmos - 2º Semestre

Este repositório reúne exercícios, exemplos e atividades desenvolvidos durante o 2º semestre da disciplina de Algoritmos, utilizando a linguagem **Python**.

O material aprofunda os conceitos estudados no semestre anterior e inclui temas como funções, arquivos, strings, matrizes, dicionários, tuplas, recursividade, busca, ordenação e programação orientada a objetos.

- Funções e modularização

## Como Executar os Arquivos

Para executar os exercícios, é necessário ter o Python instalado.

No terminal, acesse a pasta do arquivo desejado e execute:

```bash
python nome_do_arquivo.py
```

Exemplo:

```bash
python Exercicio01.py
```

Alguns arquivos dependem de outros módulos da mesma pasta. Nesses casos, execute o comando a partir da própria pasta onde os arquivos estão localizados.

## Observação

As pastas `__pycache__` são geradas automaticamente pelo Python durante a execução de alguns scripts. Elas não precisam ser alteradas manualmente.
